score ladder

One bar per solution, length = score (API). Colored segments: computed surplus per token pair; gray segment: implied fees. Black tick: baseline level for the pair (red if the segment falls short → filtered). Blue marker on a winner: the gap from the marker to the end of the bar is its reward basis (winners total − reference score, uncapped). Click a bar to locate the solution in the table.

bundle structure

Each column is a distinct bundle of directed token pairs that was bid on (dots mark the pairs it covers). Bar: best computed surplus for the bundle; ×n: number of solutions bidding exactly this bundle. Green outline: bundle is part of the winning partition (local surplus-based rerun).

    selection trace

    Step-by-step rerun of the mechanism on surplus-based scores: fairness filtering, then greedy selection by score with compatibility on directed token pairs. Click a line to locate the solution in the table. ⚠ marks disagreements with the API outcome (usually due to the missing fee component).
